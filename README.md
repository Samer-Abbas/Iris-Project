# Iris-Project
This repository contains a machine learning pipeline for classifying Iris flower species (Iris-setosa, Iris-versicolor, and Iris-virginica) using the widely recognized Iris dataset. The project includes the following components:

Data Preprocessing: Handling missing values, feature scaling, and data splitting into training and testing sets.

Exploratory Data Analysis (EDA): Visualizing data distributions, correlations, and class separability using libraries like Matplotlib and Seaborn.

Model Training: Implementation of supervised learning algorithms, including Logistic Regression, Support Vector Machines, and Random Forests, using Scikit-learn.

Evaluation: Performance metrics such as accuracy, precision, recall, F1-score, and confusion matrix are used to evaluate model performance.

The code is modular, follows best practices for reproducibility, and is suitable for both educational and practical use cases. Detailed instructions for setup and execution are included in this repository.
